This release reduces work while the watch is asleep:

- Stops periodic battery sampling during sleep; readings refresh on wake.
- Keeps the unused heart-rate sensor and accelerometer disabled.
- Uses button events and scheduled deadlines to wait asleep, while retaining
  watchdog servicing and alarm/countdown wakeups.
- Estimates battery percentage using measured PineTime discharge data.

It also includes the default-Off Touch to wake setting and the firmware-update
hold countdown above the button. The repository now provides a one-command
Linux OTA updater with optional local web controls.

A local 0.3.4 build booted on the development watch and was confirmed with KEEP.
This downloadable CI build has a different initial clock seed and package hash.
Sleep-current and overnight battery comparisons are still pending.
