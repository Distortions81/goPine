This release adds browser firmware updates and the features developed since 0.3.4.

- Update from the [goPine browser updater](https://distortions81.github.io/goPineTime/).
  Choose the offered release, connect to the watch, follow acknowledged-byte
  progress, and resume brief disconnects. Installation still requires **INSTALL**
  on the watch, followed by **KEEP** after a successful boot.
- Firmware Update now runs inside goPine, with progress, Cancel/Retry and an
  explicit install step. Installed BLE goPine 0.3.13 or newer supports this path;
  older firmware and InfiniTime recovery require one recovery/Legacy DFU update.
- Add current weather and five-day forecast, music controls and metadata, and a
  four-message Android-compatible notification inbox. Phone connections are
  opt-in: Off, Connect 10 Min, or Stay Connected. Reboot defaults to Off.
- Add six-digit passkey pairing, one saved phone bond, pairing status and Forget
  Phone. Fix a reentrant radio-shutdown path implicated in Weather → Update → Done
  crashes after a phone connection. That specific crash still needs phone testing.
- Add full-screen charging/battery notices when charging starts or stops or the
  charger is disconnected, plus a saved flipped-screen setting for the opposite
  button orientation. Charging ETA is not estimated.
- Reduce sleep wakeups, shut down unused display/SPI peripherals, skip unchanged
  drawing strips, compress font data and reduce temporary allocations. These
  changes have automated coverage; battery-life improvements remain unmeasured.

The browser page explains missing Web Bluetooth support. On Linux Chrome, enable
**Experimental Web Platform features** at
`chrome://flags/#enable-experimental-web-platform-features`, relaunch Chrome,
then reopen the updater. See [Chrome's platform guide](https://developer.chrome.com/docs/capabilities/bluetooth).
Use HTTPS, keep the watch close, disconnect phone apps and keep the updater tab
open. The watch requires at least 20% battery or external power and a confirmed
current firmware before updating.

Phone integration remains experimental. InfiniLink pairing/reconnect, weather,
music and Gadgetbridge notification delivery need device acceptance tests.
iPhone system notifications (ANCS) and system-wide iPhone media control are not
implemented; leave InfiniLink **Developer → Force ANCS off** while testing.

Validation includes Go race tests/vet, eight C ASan/UBSan harnesses, host uploader
and release tests, browser package/protocol tests, and an enforced linked-image
memory budget. A local 0.3.15 image completed an in-goPine transfer and the watch
verified it. Boot/KEEP for that image is not yet confirmed; the last confirmed
hardware baseline is 0.3.14. The downloadable release is rebuilt from the tagged
source commit, and is not claimed to have completed an on-watch smoke test.
Direct-update power-loss/rollback behavior, phone interoperability and long-run
battery endurance remain hardware checks.
